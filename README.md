# logger
A generic JSON logging library written in Javascript for Node & browser usage.

## Disclaimer
This is a personal library intended for use in my own projects. Maintaining this repo is not a top priority, but something I do based on personal need.

## Installation
This package isn’t on npm yet and might never be.  
To use it, clone the repo or copy the files into your project.

## Core ideas
Different logging levels:
Debug, Info, Warn, Error, and Fatal.
Plain JSON output.
Pluggable destinations, be it console, files, or an HTTP endpoint.
Custom context fields.

## Performance
This library is intended to be as fast as I can possibly make it while still being light and simple enough for custom modifications. Performance metrics will eventually go here as the project develops.
